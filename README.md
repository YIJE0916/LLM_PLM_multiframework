# Kinase Biology AI — RAG + ESM-2 Chatbot

An AI-powered chatbot for kinase biology that combines **retrieval-augmented generation (RAG)**, **protein language model mutation scoring (ESM-2)**, and **LLM synthesis (LLaMA-3 via Groq)** to answer scientific questions about kinase mutations and drug resistance.

---

## Demo

> *"Why does EGFR T790M cause resistance to gefitinib?"*
> *"How does BRAF V600E activate the MAPK pathway?"*
> *"Why does BCR-ABL T315I resist imatinib?"*

The system retrieves relevant literature, fetches the wildtype sequence from UniProt, scores the mutation with ESM-2, and synthesises a scientific answer.

---

## Pipeline Architecture

```
User Question
      │
      ▼
[Stage 1] Query Orchestration (LLaMA-3.1-8b)
      │  extracts: kinase, mutation, drug
      ▼
[Stage 2] RAG Retrieval (FAISS + MiniLM)
      │  retrieves top-k literature chunks
      ▼
[Stage 2b] Sequence Fetch (UniProt REST API)
      │  fetches wildtype amino acid sequence
      ▼
[Stage 3] ESM-2 Mutation Scoring
      │  ΔLL = logp(mutant) − logp(wildtype) at masked position
      ▼
[Stage 4] Cross-modal Synthesis (LLaMA-3.3-70b)
           integrates literature + PLM evidence → final answer
```

## Quickstart

### 1. Set up API Key

Create `.streamlit/secrets.toml` inside the `User Interface/` folder:

```toml
GROQ_API_KEY = "your_groq_api_key_here"
```

Or set an environment variable:

```bash
export GROQ_API_KEY="your_groq_api_key_here"
```

Get a free API key at [console.groq.com](https://console.groq.com).

### 2. Install dependencies

```bash
cd "User Interface"
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run ui_v2.py
```

## Key Components

### ESM-2 Mutation Scoring
Uses `facebook/esm2_t30_150M_UR50D` (150M parameters) to score mutations via masked language modelling. The **ΔLL** score measures how much a mutation disrupts evolutionary conservation at that position:

| ΔLL | Interpretation |
|-----|----------------|
| Near 0 | Position not conserved — mutation likely neutral |
| < −0.5 | Position conserved — mutation disrupts function |
| < −1.0 | Highly conserved — mutation almost certainly pathogenic |

### RAG Retrieval
Literature is embedded with `all-MiniLM-L6-v2` and indexed in FAISS. At query time, the top-5 chunks most relevant to the question are retrieved, with kinase-specific boosting.

### LLM Synthesis
- **Stage 1 (query parsing):** `llama-3.1-8b-instant` — fast structured extraction
- **Stage 4 (answer generation):** `llama-3.3-70b-versatile` — scientific synthesis
